# Dynamic Notch Lite settings

Mode: Operate. Native WPF, Segoe UI, dark neutral surfaces; preserve the Z mark, existing spring movement and real liquid glass.

The 1.1.0 Lite cut removes Canvas video, clipboard history, album backgrounds/glow and online lyrics/subtitles from the running window. No local AI/ONNX or embedded browser runtime is shipped. Removed-feature keys are forced off when an older profile is loaded or applied. Original user data is retained.

One settings window replaces the old appearance/feature/advanced windows. Four sections: Appearance, Features, Updates, About & support. English and Vietnamese only, including the language picker, messages and file shelf. Desktop minimum width 580 DIP; scrolling must leave slider values and keyboard focus visible.

Native settings colors: background #111215, action surface #EBEDF0, action ink #000000, primary copy #FFFFFF, secondary copy #D3D3D3. File shelf uses a low-opacity white row surface; source paths use the same white primary copy. These neutral additions belong to the standalone Notch editor, not the older light taskbar editor palette.

Keep music/artwork, clock, battery, timer, app mixer, a path-only file shelf, copy/Codex notifications, startup and verified GitHub updates. File shelf removal removes a reference, never a source file.

Verification uses private-desktop WPF renders and isolated profiles, not captures or clicks on the user's desktop. Measure the installed process separately before claiming RAM savings. Existing taskbar/Quick Settings/thumbnail helper is outside this change.
