# Zuzong Dynamic Lite

## Tiếng Việt

Lite giữ nhạc từ Windows, ảnh bìa tĩnh, đồng hồ, pin, hẹn giờ, mixer, khay file, thông báo sao chép/Codex và kính lỏng tùy chỉnh. Không cần đăng nhập Spotify trong app để đọc phiên nhạc Windows.

Đã bỏ video Canvas, lịch sử clipboard, nền/vầng sáng bìa album và lời nhạc/phụ đề trực tuyến. Các trang AI/dịch cục bộ, camera, thời tiết và tiện ích phụ không được cung cấp trong Lite. Hồ sơ/clipboard cũ không bị xóa.

Mở app để chỉnh giao diện. Chọn English hoặc Tiếng Việt ở góc phải, rồi nhấn Lưu. Tắt tính năng không cần ở tab Tính năng. Khay file chỉ lưu tối đa 24 đường dẫn; kéo file ra ứng dụng khác để dùng. Bỏ khỏi khay không xóa file gốc.

Đóng cài đặt vẫn giữ Notch chạy nền. Thoát qua biểu tượng ở khay hệ thống. Bật Chạy khi mở máy nếu muốn tự khởi động. Vào Cập nhật để kiểm tra GitHub; kiểm tra nền và beta là tùy chọn.

Windows 10 2004+ / Windows 11 x64. Bộ cài kèm .NET. Dữ liệu ở `%LOCALAPPDATA%\ZuzongDynamic`. Kính có thể không xuất hiện trong bản ghi/chụp màn hình do cơ chế loại chính Notch khỏi nguồn nền.

## English

Lite keeps Windows media playback, static artwork, clock, battery, timer, volume mixer, file shelf, copied/Codex notices and customizable liquid glass. Windows media sessions do not require a separate Spotify login inside the app.

Canvas video, clipboard history, album glow and online lyrics/subtitles are removed. Local AI/translation, camera, weather and extra widgets are not offered in Lite. Previous profiles and clipboard files are preserved.

Select English or Tiếng Việt in the top-right corner and save. The Features tab controls the remaining modules. The file shelf stores up to 24 original paths. Drag files out to another app; removing a shelf entry does not delete the original file.

Closing settings leaves the Notch running. Quit through its system-tray icon. Use Start with Windows for automatic startup, and Updates for GitHub releases. Background checks and beta releases are optional.

Windows 10 2004+ / Windows 11 x64. The installer includes .NET. User data is stored in `%LOCALAPPDATA%\ZuzongDynamic`. Glass can be absent from screenshots/recordings because the Notch is excluded from its own backdrop capture.
